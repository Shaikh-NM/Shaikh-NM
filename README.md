<summary><b>🧠 The pattern behind all three (click to expand)</b></summary>
<br/>

```mermaid
flowchart LR
    C([Client]) -->|HTTP + JWT| GW[API Gateway<br/>routing • auth • rate limit]
    GW --> S1[Service A]
    GW --> S2[Service B]
    GW --> S3[Service C]
    S1 <-->|events| K{{Apache Kafka}}
    S2 <-->|events| K
    S3 <-->|events| K
    S1 --- R[(Redis<br/>cache • OTP • counters)]
    S2 --- DB[(Database<br/>per service)]
    S3 --- X[(S3 / external APIs)]
```

Synchronous calls only where an immediate answer is required; everything else flows through events, with idempotent consumers and compensating actions for failure.
